## Du plus utile au moins utile

| ⌘L | Place le point d’insertion dans la zone de recherche/titre |
| Échap | Efface la recherche en cours |
| Retour | Commence l’édition de la note, en la créant si nécessaire |
| Tab | Déplace le point d’insertion entre les zones de texte |
| ⌘K | Sélectionne la note précédente dans la liste |
| ⌘J | Sélectionne la note suivante dans la liste |
| ⌘D | Désélectionne la note active et restaure le texte recherché |
| ⇧⌘V | Colle le contenu du presse-papiers dans une nouvelle note |
| ⌘R | Renomme la note sélectionnée |
| ⌘⌫ | Supprime la ou les notes sélectionnées |
| ⇧⌘T | Étiquette la note sélectionnée |
| ⌘G | Occurrence suivante du texte recherché |
| ⇧⌘G | Occurrence précédente du texte recherché |
| ⌘Retour | Ouvre l’URL sous le point d’insertion |
| ⌘← | Passe à l’édition du titre depuis le début du corps de la note |
| ⌘→ | Passe au corps de la note depuis la fin du titre |
| ⇧⌘D | Ajoute la note sélectionnée aux signets |
| ⌘P | Imprime la ou les notes sélectionnées |
| ⌘E | Exporte la ou les notes sélectionnées dans d’autres formats |

## Rechercher et créer des notes

| ↑ ↓ | Dans le champ de recherche : parcourt la liste des notes |
| ⌘↑ ⌘↓ | Première ou dernière note de la liste |
| fn← fn→ | Dans la liste des notes : première ou dernière note (ou Home, End) |
| fn↑ fn↓ | Dans la liste des notes : page précédente ou suivante (ou Page Up, Page Down) |
| ⇧⌘N | Affiche la fenêtre principale |

## Notes

| ⌥⌘C | Copie le lien de la note |
| ⇧⌘R | Affiche dans le Finder |
| ⇧⌘P | Mise en page |

## Signets

| ⌘0 | Affiche les signets |
| ⌘1 – ⌘9 | Va à un signet |

## Édition

| ⌘Retour | Hors d’un lien : commence une nouvelle ligne en dessous |
| ⇧⌘Retour | Commence une nouvelle ligne au-dessus |
| ⌘⌫ | Dans une note : supprime jusqu’au début de la ligne |
| Tab | Dans une note : indente ou passe au champ suivant, selon le réglage « Tabulation » |
| ⌥Tab | Indente |
| ⌥⌘V | Colle l’URL copiée sous forme de lien Markdown |
| ⌘F | Rechercher |
| ⌥⌘F | Rechercher et remplacer |
| ⌥⌘E | Chercher à partir de la sélection |
| ⌥⌘J | Affiche la sélection |
| ⌘: | Affiche l’orthographe et la grammaire |
| ⌘; | Vérifie l’orthographe |

## Mise en forme

| ⌘B | Gras |
| ⌘I | Italique |
| ⌘Y | Barré |
| ⌘T | Texte brut (supprime les styles) |
| ⌘] | Décale à droite (augmente le retrait des lignes) |
| ⌘[ | Décale à gauche (réduit le retrait des lignes) |

> Le gras, l’italique et le barré ne sont enregistrés que si les notes sont stockées en RTF ou en HTML (Préférences › Notes).

## Markdown

| ⇧⌘M | Active ou désactive la complétion Markdown |
| ⌘> | Ajoute un niveau de citation (>) aux lignes sélectionnées |
| ⌘< | Retire un niveau de citation |
| ⌘+ | Ajoute un niveau de titre (#) |
| ⌘− | Retire un niveau de titre |

> Les raccourcis de citation et de titre fonctionnent lorsque la complétion Markdown est activée.

## Aperçu

| ⌃⌘P | Affiche ou masque l’aperçu |
| ⌃⌘M | Aperçu dans Marked |
| ⌘U | Bascule entre l’aperçu et sa source HTML |
| ⌥⇧⌘L | Verrouille l’aperçu sur la note active |
| ⌥⇧⌘P | Imprime l’aperçu ou l’enregistre en PDF |
| ⇧⌘S | Enregistre l’aperçu en HTML |

## Présentation

| ⌥⌘L | Bascule entre la présentation verticale et horizontale |
| ⇧⌘C | Replie ou déplie la liste des notes |
| ⌥⌘1 | Jeu de couleurs B/W |
| ⌥⌘2 | Jeu de couleurs Low Contrast |
| ⌥⌘3 | Jeu de couleurs de l’utilisateur (User Scheme) |
| ⇧⌘K | Affiche ou masque le nombre de mots |
| ⌥⌘P | Affiche ou masque l’aperçu des notes dans la liste |
