## In der Reihenfolge vom nützlichsten zum weniger nützlichen Tastenkürzel

| ⌘L | Einfügemarke in das Such- bzw. Titelfeld setzen |
| Esc | Aktuelle Suche löschen |
| Zeilenschalter | Notiz bearbeiten oder, falls nötig, anlegen |
| Tab | Einfügemarke zwischen den Textbereichen wechseln |
| ⌘K | Vorige Notiz in der Liste wählen |
| ⌘J | Nächste Notiz in der Liste wählen |
| ⌘D | Auswahl der aktuellen Notiz aufheben und Suchtext wiederherstellen |
| ⇧⌘V | Inhalt der Zwischenablage als neue Notiz einfügen |
| ⌘R | Ausgewählte Notiz umbenennen |
| ⌘⌫ | Ausgewählte Notiz(en) löschen |
| ⇧⌘T | Ausgewählte Notiz mit Etikett versehen |
| ⌘G | Nächstes Vorkommen des Suchtextes finden |
| ⇧⌘G | Voriges Vorkommen des Suchtextes finden |
| ⌘Zeilenschalter | URL an der Einfügemarke öffnen |
| ⌘← | Zum Bearbeiten des Titels springen, wenn am Anfang des Notizinhalts |
| ⌘→ | Zum Notizinhalt springen, wenn am Ende des Titels |
| ⇧⌘D | Ausgewählte Notiz als Lesezeichen hinzufügen |
| ⌘P | Ausgewählte Notiz(en) drucken |
| ⌘E | Ausgewählte Notiz(en) in andere Formate exportieren |

## Suchen und Notizen anlegen

| ↑ ↓ | Im Suchfeld: durch die Notizliste blättern |
| ⌘↑ ⌘↓ | Erste bzw. letzte Notiz der Liste |
| ⇧⌘N | Hauptfenster anzeigen |

## Notizen

| ⌥⌘C | Link zur Notiz kopieren |
| ⇧⌘R | Im Finder anzeigen |
| ⇧⌘P | Seite einrichten |

## Lesezeichen

| ⌘0 | Lesezeichen anzeigen |
| ⌘1 – ⌘9 | Zu einem Lesezeichen wechseln |

## Bearbeiten

| ⌘Zeilenschalter | Nicht auf einem Link: neue Zeile darunter beginnen |
| ⇧⌘Zeilenschalter | Neue Zeile darüber beginnen |
| ⌘⌫ | In einer Notiz: bis zum Zeilenanfang löschen |
| Tab | In einer Notiz: einrücken oder zum nächsten Feld wechseln, je nach Einstellung „Tabulatortaste“ |
| ⌥Tab | Einrücken |
| ⌥⌘V | Kopierte URL als Markdown-Link einfügen |
| ⌘F | Suchen |
| ⌥⌘F | Suchen und Ersetzen |
| ⌥⌘E | Auswahl suchen |
| ⌥⌘J | Auswahl anzeigen |
| ⌘: | Rechtschreibung und Grammatik anzeigen |
| ⌘; | Rechtschreibung prüfen |

## Formatierung

| ⌘B | Fett |
| ⌘I | Kursiv |
| ⌘Y | Durchgestrichen |
| ⌘T | Als einfachen Text darstellen (Formatierungen entfernen) |
| ⌘] | Rechts einrücken (Zeilen einrücken) |
| ⌘[ | Links einrücken (Zeilen ausrücken) |

> Fett, kursiv und durchgestrichen werden nur gesichert, wenn Notizen als RTF oder HTML gespeichert werden (Einstellungen › Notizen).

## Markdown

| ⇧⌘M | Markdown-Vervollständigung ein- oder ausschalten |
| ⌘> | Den ausgewählten Zeilen eine Zitatebene (>) hinzufügen |
| ⌘< | Eine Zitatebene entfernen |
| ⌘+ | Eine Überschriftenebene (#) hinzufügen |
| ⌘− | Eine Überschriftenebene entfernen |

> Die Kürzel für Zitate und Überschriften funktionieren, solange die Markdown-Vervollständigung eingeschaltet ist.

## Vorschau

| ⌃⌘P | Vorschau ein- oder ausblenden |
| ⌃⌘M | Vorschau in Marked |
| ⌘U | Zwischen Vorschau und HTML-Quelltext wechseln |
| ⌥⇧⌘L | Vorschau auf die aktuelle Notiz fixieren |
| ⌥⇧⌘P | Vorschau drucken oder als PDF sichern |
| ⇧⌘S | Vorschau als HTML-Datei sichern |

## Darstellung

| ⌥⌘L | Zwischen vertikaler und horizontaler Darstellung wechseln |
| ⇧⌘C | Notizliste ein- oder ausklappen |
| ⌥⌘1 | Farbschema B/W |
| ⌥⌘2 | Farbschema „Niedriger Kontrast“ |
| ⌥⌘3 | Nutzer-Farbschema |
| ⇧⌘K | Wortanzahl ein- oder ausblenden |
| ⌥⌘P | Notizvorschau in der Liste ein- oder ausblenden |

## Überall
