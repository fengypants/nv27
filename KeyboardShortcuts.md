## Searching and creating notes

| ⌘L | Go to the search field |
| Return | In the search field: edit the selected note, or create a note titled with the search text |
| Esc | Clear the search |
| ↑ ↓ | In the search field: move through the notes list |
| ⌘J | Next note |
| ⌘K | Previous note |
| ⌘↑ ⌘↓ | First or last note in the list |
| ⌘D | Deselect the note and return to the search text |
| Tab | Move from the search field to the note |
| ⇧⌘N | Show the main window |

## Notes

| ⌘R | Rename |
| ⌘← | Rename, when the insertion point is at the start of the note |
| ⇧⌘T | Tag |
| ⌘⌫ | Delete the selected notes (from the notes list or search field) |
| ⇧⌘V | Paste as a new note |
| ⌥⌘C | Copy the note's link |
| ⌘E | Export |
| ⇧⌘R | Show in Finder |
| ⇧⌘P | Page Setup |
| ⌘P | Print |

## Bookmarks

| ⇧⌘D | Add to Bookmarks |
| ⌘0 | Show Bookmarks |
| ⌘1 – ⌘9 | Go to a bookmark |

## Editing

| ⌘Return | Open the link at the insertion point; elsewhere, start a new line below |
| ⇧⌘Return | Start a new line above |
| ⌘⌫ | Delete to the start of the line |
| Tab | Move to the next field, or indent, depending on the Tab Key setting |
| ⌥Tab | Indent |
| ⌥⌘V | Paste the copied URL as a Markdown link |
| ⌘F | Find |
| ⌥⌘F | Find and Replace |
| ⌘G | Find Next |
| ⇧⌘G | Find Previous |
| ⌥⌘E | Use Selection for Find |
| ⌥⌘J | Jump to Selection |
| ⌘: | Show Spelling and Grammar |
| ⌘; | Check Spelling |

## Formatting

| ⌘B | Bold |
| ⌘I | Italic |
| ⌘Y | Strikethrough |
| ⌘T | Plain Text Style (remove styles) |
| ⌘] | Shift Right (indent lines) |
| ⌘[ | Shift Left (outdent lines) |

> Bold, italic and strikethrough are saved only when notes are stored as Rich Text or HTML (Settings › Notes).

## Markdown

| ⇧⌘M | Turn Markdown completion on or off |
| ⌘> | Add a quote level (>) to the selected lines |
| ⌘< | Remove a quote level |
| ⌘+ | Add a heading level (#) |
| ⌘− | Remove a heading level |

> The quote and heading shortcuts work while Markdown completion is on.

## Preview

| ⌃⌘P | Show or hide the preview |
| ⌃⌘M | Preview in Marked |
| ⌘U | Switch between the preview and its HTML source |
| ⌥⇧⌘L | Lock the preview to the current note |
| ⌥⇧⌘P | Print the preview or save it as PDF |
| ⇧⌘S | Save the preview as HTML |

## View

| ⌥⌘L | Switch between vertical and horizontal layout |
| ⇧⌘C | Collapse or expand the notes list |
| ⌥⌘1 | B/W color scheme |
| ⌥⌘2 | Low Contrast color scheme |
| ⌥⌘3 | User color scheme |
| ⇧⌘K | Show or hide the word count |
| ⌥⌘P | Show or hide note previews in the list |
