## In ordine di utilità decrescente

| ⌘L | Porta il cursore nel campo di ricerca/titolo |
| Esc | Cancella la ricerca corrente |
| A capo | Attiva la modifica della nota o, se necessario, la crea |
| Tab | Sposta il cursore tra le aree di testo |
| ⌘K | Seleziona la nota precedente nell’elenco |
| ⌘J | Seleziona la nota successiva nell’elenco |
| ⌘D | Deseleziona la nota corrente, ripristinando il testo della ricerca |
| ⇧⌘V | Incolla il contenuto degli appunti come nuova nota |
| ⌘R | Rinomina la nota selezionata |
| ⌘⌫ | Elimina la nota o le note selezionate |
| ⇧⌘T | Etichetta la nota selezionata |
| ⌘G | Trova la successiva ricorrenza del testo cercato |
| ⇧⌘G | Trova la precedente ricorrenza del testo cercato |
| ⌘A capo | Apre l’URL su cui si trova il cursore |
| ⌘← | Porta il cursore nel titolo quando si trova all’inizio del corpo della nota |
| ⌘→ | Porta il cursore nel corpo della nota quando si trova alla fine del titolo |
| ⇧⌘D | Aggiunge la nota selezionata ai segnalibri |
| ⌘P | Stampa la nota o le note selezionate |
| ⌘E | Esporta la nota o le note selezionate in altri formati |

## Cercare e creare note

| ↓ | Nel campo di ricerca: passa alla prima nota dell’elenco |
| ⌘↑ ⌘↓ | Prima o ultima nota dell’elenco |
| fn← fn→ | Nell’elenco delle note: prima o ultima nota (oppure Home, End) |
| fn↑ fn↓ | Nell’elenco delle note: pagina precedente o successiva (oppure Page Up, Page Down) |
| ⇧⌘N | Mostra la finestra principale |

## Note

| ⌥⌘C | Copia il link della nota |
| ⇧⌘R | Mostra nel Finder |
| ⇧⌘P | Formato di stampa |

## Segnalibri

| ⌘0 | Mostra i segnalibri |
| ⌘1 – ⌘9 | Va a un segnalibro |

## Modifica

| ⌘A capo | Fuori da un link: inizia una nuova riga sotto |
| ⇧⌘A capo | Inizia una nuova riga sopra |
| ⌘⌫ | In una nota: elimina fino all’inizio della riga |
| Tab | In una nota: aumenta il rientro o passa al campo successivo, secondo l’impostazione «Tasto Tab» |
| ⌥Tab | Aumenta il rientro |
| ⌥⌘V | Incolla l’URL copiato come link Markdown |
| ⌘F | Trova |
| ⌥⌘F | Trova e sostituisci |
| ⌥⌘E | Usa selezione per ricerca |
| ⌥⌘J | Mostra la selezione |
| ⌘: | Mostra ortografia e grammatica |
| ⌘; | Controlla ortografia |

## Formattazione

| ⌘B | Grassetto |
| ⌘I | Corsivo |
| ⌘Y | Barrato |
| ⌘T | Testo semplice (rimuove gli stili) |
| ⌘] | Aumenta il rientro delle righe |
| ⌘[ | Riduce il rientro delle righe |

> Con il completamento Markdown attivo (⇧⌘M), ⌘B, ⌘I e ⌘Y aggiungono Markdown attorno alla selezione: due asterischi per il grassetto, uno per il corsivo, due tilde per il barrato. Se è disattivato, formattano il testo nelle note archiviate come RTF o HTML (Impostazioni › Note). Le note in testo semplice non possono conservare la formattazione, quindi lì non sono disponibili.

## Markdown

| ⇧⌘M | Attiva o disattiva il completamento Markdown |
| ⌘> | Aggiunge un livello di citazione (>) alle righe selezionate |
| ⌘< | Rimuove un livello di citazione |
| ⌘+ | Aggiunge un livello di intestazione (#) |
| ⌘− | Rimuove un livello di intestazione |

> Le scorciatoie per citazioni e intestazioni funzionano quando il completamento Markdown è attivo.

## Anteprima

| ⌃⌘P | Mostra o nasconde l’anteprima |
| ⌃⌘M | Anteprima in Marked |
| ⌘U | Passa dall’anteprima al sorgente HTML e viceversa |
| ⌥⇧⌘L | Blocca l’anteprima sulla nota corrente |
| ⌥⇧⌘P | Stampa l’anteprima o la salva come PDF |
| ⇧⌘S | Salva l’anteprima come HTML |

## Vista

| ⌥⌘L | Passa dalla disposizione verticale a quella orizzontale e viceversa |
| ⇧⌘C | Comprime o espande l’elenco delle note |
| ⌥⌘1 | Schema colori B/W |
| ⌥⌘2 | Schema colori Low Contrast |
| ⌥⌘3 | Schema colori dell’utente (User Scheme) |
| ⇧⌘K | Mostra o nasconde il conteggio delle parole |
| ⌥⌘P | Mostra o nasconde l’anteprima delle note nell’elenco |
