## Por ordem de utilidade, da mais à menos útil

| ⌘L | Coloca o cursor na área de pesquisa/título |
| Esc | Apaga a pesquisa atual |
| Return | Começa a editar a nota, criando-a se necessário |
| Tab | Move o cursor entre as áreas de texto |
| ⌘K | Seleciona a nota anterior na lista |
| ⌘J | Seleciona a nota seguinte na lista |
| ⌘D | Desmarca a nota atual, repondo o texto da pesquisa |
| ⇧⌘V | Cola o conteúdo da área de transferência como nova nota |
| ⌘R | Muda o nome da nota selecionada |
| ⌘⌫ | Apaga a(s) nota(s) selecionada(s) |
| ⇧⌘T | Etiqueta a nota selecionada |
| ⌘G | Procura a ocorrência seguinte do texto pesquisado |
| ⇧⌘G | Procura a ocorrência anterior do texto pesquisado |
| ⌘Return | Abre o URL sob o cursor |
| ⌘← | Passa à edição do título quando no início do corpo da nota |
| ⌘→ | Passa ao corpo da nota quando no fim do título |
| ⇧⌘D | Adiciona a nota selecionada aos marcadores |
| ⌘P | Imprime a(s) nota(s) selecionada(s) |
| ⌘E | Exporta a(s) nota(s) selecionada(s) para outros formatos |

## Pesquisar e criar notas

| ↓ | No campo de pesquisa: passa para a primeira nota da lista |
| ⌘↑ ⌘↓ | Primeira ou última nota da lista |
| fn← fn→ | Na lista de notas: primeira ou última nota (ou Home, End) |
| fn↑ fn↓ | Na lista de notas: página anterior ou seguinte (ou Page Up, Page Down) |
| ⇧⌘N | Mostra a janela principal |

## Notas

| ⌥⌘C | Copia a ligação da nota |
| ⇧⌘R | Mostra no Finder |
| ⇧⌘P | Configuração de página |

## Marcadores

| ⌘0 | Mostra os marcadores |
| ⌘1 – ⌘9 | Vai para um marcador |

## Edição

| ⌘Return | Fora de uma ligação: começa uma nova linha abaixo |
| ⇧⌘Return | Começa uma nova linha acima |
| ⌘⌫ | Numa nota: apaga até ao início da linha |
| Tab | Numa nota: aumenta o recuo ou passa ao campo seguinte, consoante a definição «Tecla Tab» |
| ⌥Tab | Aumenta o recuo |
| ⌥⌘V | Cola o URL copiado como ligação Markdown |
| ⌘F | Procurar |
| ⌥⌘F | Procurar e substituir |
| ⌥⌘E | Procurar utilizando o texto selecionado |
| ⌥⌘J | Mostrar a seleção |
| ⌘: | Mostra a ortografia e gramática |
| ⌘; | Verifica a ortografia |

## Formatação

| ⌘B | Negrito |
| ⌘I | Itálico |
| ⌘Y | Tachado |
| ⌘T | Texto simples (remove os estilos) |
| ⌘] | Aumenta o recuo das linhas |
| ⌘[ | Diminui o recuo das linhas |

> Com o preenchimento automático de Markdown ativo (⇧⌘M), ⌘B, ⌘I e ⌘Y acrescentam Markdown à volta da seleção: dois asteriscos para negrito, um para itálico, dois tis para tachado. Desativado, formatam o texto das notas armazenadas em RTF ou HTML (Definições › Notas). As notas em texto simples não conseguem guardar formatação, por isso aí não estão disponíveis.

## Markdown

| ⇧⌘M | Ativa ou desativa o preenchimento automático de Markdown |
| ⌘> | Adiciona um nível de citação (>) às linhas selecionadas |
| ⌘< | Remove um nível de citação |
| ⌘+ | Adiciona um nível de cabeçalho (#) |
| ⌘− | Remove um nível de cabeçalho |

> Os atalhos de citação e cabeçalho funcionam enquanto o preenchimento automático de Markdown estiver ativo.

## Pré-visualização

| ⌃⌘P | Mostra ou oculta a pré-visualização |
| ⌃⌘M | Pré-visualizar no Marked |
| ⌘U | Alterna entre a pré-visualização e o código HTML |
| ⌥⇧⌘L | Fixa a pré-visualização na nota atual |
| ⌥⇧⌘P | Imprime a pré-visualização ou guarda-a em PDF |
| ⇧⌘S | Guarda a pré-visualização em HTML |

## Visualização

| ⌥⌘L | Alterna entre o esquema vertical e horizontal |
| ⇧⌘C | Recolhe ou expande a lista de notas |
| ⌥⌘1 | Esquema de cores B/W |
| ⌥⌘2 | Esquema de cores Low Contrast |
| ⌥⌘3 | Esquema de cores do utilizador (User Scheme) |
| ⇧⌘K | Mostra ou oculta a contagem de palavras |
| ⌥⌘P | Mostra ou oculta a pré-visualização das notas na lista |
