## 按从最常用到最不常用的顺序

| ⌘L | 将插入点移到搜索/标题区域 |
| Esc | 清除当前搜索 |
| Return | 开始编辑笔记，必要时新建笔记 |
| Tab | 在文本区域之间移动插入点 |
| ⌘K | 选择列表中的上一个笔记 |
| ⌘J | 选择列表中的下一个笔记 |
| ⌘D | 取消选择当前笔记，恢复搜索文本 |
| ⇧⌘V | 将剪贴板内容粘贴为新笔记 |
| ⌘R | 重命名所选笔记 |
| ⌘⌫ | 删除所选笔记 |
| ⇧⌘T | 为所选笔记添加标签 |
| ⌘G | 查找搜索文本的下一个匹配项 |
| ⇧⌘G | 查找搜索文本的上一个匹配项 |
| ⌘Return | 打开插入点处的 URL |
| ⌘← | 在笔记正文开头时，转到编辑标题 |
| ⌘→ | 在标题末尾时，转到笔记正文 |
| ⇧⌘D | 将所选笔记添加到书签 |
| ⌘P | 打印所选笔记 |
| ⌘E | 将所选笔记导出为其他格式 |

## 搜索和创建笔记

| ↓ | 在搜索栏中：转到列表中的第一个笔记 |
| ⌘↑ ⌘↓ | 列表中的第一个或最后一个笔记 |
| fn← fn→ | 在笔记列表中：第一个或最后一个笔记（或 Home、End） |
| fn↑ fn↓ | 在笔记列表中：向上或向下翻页（或 Page Up、Page Down） |
| ⇧⌘N | 显示主窗口 |

## 笔记

| ⌥⌘C | 拷贝笔记的链接 |
| ⇧⌘R | 在 Finder 中显示 |
| ⇧⌘P | 页面设置 |

## 书签

| ⌘0 | 显示书签 |
| ⌘1 – ⌘9 | 前往书签 |

## 编辑

| ⌘Return | 不在链接上时：在下方开始新行 |
| ⇧⌘Return | 在上方开始新行 |
| ⌘⌫ | 在笔记中：删除到行首 |
| Tab | 在笔记中：缩进或移到下一个栏位，取决于“Tab 键”设置 |
| ⌥Tab | 缩进 |
| ⌥⌘V | 将拷贝的 URL 粘贴为 Markdown 链接 |
| ⌘F | 查找 |
| ⌥⌘F | 查找和替换 |
| ⌥⌘E | 查找所选内容 |
| ⌥⌘J | 跳到所选内容 |
| ⌘: | 显示拼写和语法 |
| ⌘; | 检查拼写 |

## 格式

| ⌘B | 粗体 |
| ⌘I | 斜体 |
| ⌘Y | 删除线 |
| ⌘T | 纯文本样式（移除样式） |
| ⌘] | 向右缩进（增加行缩进） |
| ⌘[ | 向左缩进（减少行缩进） |

> 只有当笔记以 RTF 或 HTML 格式存储时，才会保存粗体、斜体和删除线（偏好设置 › 笔记）。

## Markdown

| ⇧⌘M | 打开或关闭 Markdown 自动补全 |
| ⌘> | 为所选行添加一级引用（>） |
| ⌘< | 移除一级引用 |
| ⌘+ | 添加一级标题（#） |
| ⌘− | 移除一级标题 |

> 引用和标题快捷键仅在 Markdown 自动补全打开时有效。

## 预览

| ⌃⌘P | 显示或隐藏预览 |
| ⌃⌘M | 在 Marked 中预览 |
| ⌘U | 在预览与其 HTML 源代码之间切换 |
| ⌥⇧⌘L | 将预览锁定到当前笔记 |
| ⌥⇧⌘P | 打印预览或存储为 PDF |
| ⇧⌘S | 将预览存储为 HTML |

## 显示

| ⌥⌘L | 在纵向和横向排版之间切换 |
| ⇧⌘C | 折叠或展开笔记列表 |
| ⌥⌘1 | B/W 配色方案 |
| ⌥⌘2 | Low Contrast 配色方案 |
| ⌥⌘3 | 用户配色方案（User Scheme） |
| ⇧⌘K | 显示或隐藏字数统计 |
| ⌥⌘P | 在列表中显示或隐藏笔记预览 |

## 任何时候

| 你的快捷键 | 从任何应用将 nv27 调到最前面。在“偏好设置 › 常规”中设置。 |
